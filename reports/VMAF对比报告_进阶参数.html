结论

1. ICQ 质量模式下，绝大多数进阶参数是空操作：extbrc / 前向预分析(look_ahead_depth) / rdo / refs / adaptive_i / adaptive_b / b_strategy / low_power / transform_skip 传了也不改变输出（AV1 激进档与基线档结果完全相同）。真正会改变 ICQ 输出的只有 B 帧相关（bf、p_strategy、gpb）和 mbbrc。
2. ICQ 下「保守」档反而是负优化：关掉 B 帧/GPB 后码率大涨（AV1 保守档码率翻倍）而 VMAF 只高一点点，效率明显不如默认参数；默认（基线）档的效率最好。
3. 只有在固定码率模式（VBR）下，进阶参数才拉开差距：同码率下 激进 ≥ 推荐 > 保守，HEVC 上激进档比保守档高约 +0.8~1.4 VMAF，1290p 素材上差距最大。
4. 前向预分析在本驱动不可用：VBR + -look_ahead_depth 会直接报 Invalid data 崩掉（脚本注释里也记录了这点），这批 VBR 的推荐/激进档都是自动降级去掉 look_ahead_depth 后编出来的（extbrc 仍为 ON）。
5. CQP vs ICQ：调 QP 到同码率后，HEVC 上 ICQ 高约 +0.4~2.0 VMAF，AV1 上两者基本持平（±0.15 内）。ICQ 的整体码率分配更聪明，日常推荐继续用 ICQ（-global_quality）。
